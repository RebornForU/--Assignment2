NVIDIA vs Tesla：AI热度如何重塑股价

项目说明文档

本作品展示了自2021年以来，AI行业热度与科技巨头股价之间的深度联动关系。

1. 研究问题

本项目旨在解答一个核心问题：生成式AI（以ChatGPT为代表）的爆发，是如何重塑科技巨头股价走势的？

具体而言，同为具有强烈“AI标签”的企业，NVIDIA（代表AI算力底层基础设施）与 Tesla（代表AI端侧应用与自动驾驶）的股价，在面对这波“AI行业热度”时，是否产生了真实的相关性与走势分化？

2. 设计决策与替代方案

  • 特定的可视化编码：
    1. 为了消除两只股票绝对价格的巨大差异，我没有使用原始收盘价，而是通过前端计算将其编码为“相对于起始日的百分比涨跌幅”，并采用高对比度折线（绿/红）表示。
    2. 将“AI搜索热度”编码为幽蓝色的面积图（Area Chart）并置于最底层。这种编码方式既能传达“行业背景浪潮”的隐喻，又不会喧宾夺主遮挡股价折线。
  • 交互技术：
    采用了经典的 Focus + Context（全局刷选+局部放大） 模式，结合鼠标悬浮的工具提示（Tooltip）。这允许用户在长达五年的时间轴中，精准缩放到特定事件（如财报发布）前后，观察剧烈的市场波动。
  • 曾考虑过的替代方案：
    最初考虑过使用“分面图（Faceted charts）”，即把 NVDA、TSLA 和 AI热度分成上下三个独立的子图。但最终被否决，因为分离的视图破坏了人眼对时间序列趋势的直接对比能力（相关性直觉）。
  • 最终选择的依据：
    最终选定了独立双 Y 轴复合图层（Dual-Axis Layered Chart）。只有在同一个二维空间内将指标重叠，并加入“0%水平基准线”和“防重叠阶梯式事件垂直线”，才能以最震撼的视觉效果揭示 NVDA 与 AI 热度的“完美拟合”，以及 TSLA 的“逆势背离”。

3. 外部资源引用

  • 数据源 1（股票价格）： Yahoo Finance (雅虎财经)。提取了 NVDA 与 TSLA 过去五年的日线级历史交易数据（CSV 格式）。
  • 数据源 2（AI 行业热度）： Google Trends (谷歌趋势)。提取了过去五年全球范围内对关键词 "ChatGPT" 及 "Generative AI" 的搜索热度指数（0-100）。
  • 技术框架： 本项目网页骨架基于 Vue 3 (CDN)，核心交互式图表完全基于华盛顿大学交互式数据实验室开发的 Vega-Lite 语法规范构建，并使用 Vega-Embed 进行渲染。

4. 开发流程概述与耗时评估

本项目由单人独立开发完成，总耗时约 12-14 小时。整体流程分为数据收集与清洗、可视化基础构建、交互与多视图协调设计、以及UI深度美化四个阶段。

耗时最多的环节：

  • 数据清洗与格式统一（约 4 小时）： 这是最耗时的部分。由于 CSV 文件中的日期带有中文字符（如“下午04:00:00”），导致底层图表库无法识别。最终通过在 Vue 实例中编写正则表达式和字符串切割函数，将所有异构日期强制转换为标准的时间戳才得以解决。
  • 多图层联动与防重叠逻辑（约 5 小时）： 在 Vega-Lite 中实现双 Y 轴并不难，但要让底层面积图、中层折线图、事件基准线，以及“阶梯式错位排列的文字标签”在进行 Context 刷选缩放时能完美保持相对位置且不报错，花费了大量时间调试 `resolve` 和 `scale` 属性。
  • 前端网页设计调整（约 3 小时）： 为贴合 AI 主题，对原始的白底图表进行了深度的 CSS 和 Vega Global Config 覆写，调整了所有坐标轴、网格线的颜色，以达到最佳的视觉信噪比。
